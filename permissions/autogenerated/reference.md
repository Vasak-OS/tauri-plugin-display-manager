## Default Permission

Leer y cambiar el brillo de las pantallas, y leer y guardar la configuración de la luz nocturna.

#### This default permission set includes the following:

- `allow-get-brightness`
- `allow-set-brightness`
- `allow-refresh-brightness`
- `allow-get-night-light`
- `allow-set-night-light`
